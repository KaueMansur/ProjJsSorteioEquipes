## 💻 Sobre o Projeto

Este projeto foi desenvolvido para facilitar o sorteio de equipes. Inicialmente pensado para lives onde o streamer joga com seus espectadores, ele vai além: permite sortear equipes com um número ilimitado de participantes, definir a quantidade de times e até mesmo personalizá-los com nomes próprios!

---

## 🧠 Principais Funcionalidades

* 🧑 **Adicionar participante:** Insira os nomes dos participantes para o sorteio.
* 🤚 **Limite de participantes:** Controle a quantidade máxima de pessoas permitidas.
* 👪 **Definir quantidade de equipes:** Escolha em quantos times o grupo será dividido.
* 🍀 **Sortear equipes:** Distribui os participantes de forma equilibrada entre as equipes criadas.
* 🚫 **Excluir participante:** Remova participantes individualmente se necessário.
* 🚫 **Excluir equipe:** Apague equipes indesejadas.
* ✏️ **Editar equipe:** Altere os nomes das equipes para personalizá-las.
* 📱 **Layout Responsivo:** Otimizado para visualização e uso tanto no computador quanto no celular.
